# Reference

Background the morning routine reads before it searches. Checked
2026-10-14 by a research pass: every fact carries its source URL, and
anything not confirmed is marked UNVERIFIED. Treat UNVERIFIED lines as
"do not print as fact".

| File | What |
|---|---|
| `sources.md` | What can actually be fetched each morning (and what is blocked), plus a precomputed almanac for the run |
| `regs.md` | NC recreational limits and seasons for the window, with proclamation numbers |
| `spots.md` | Piers (hours, fees, blanket licences), the south end, ramps, tackle shops |
| `fall-bite.md` | What typically bites in late Oct / early Nov, kept apart from this year's reports |
| `calendar.md` | Dated events and notices Oct 29 - Nov 7 with confidence levels |
| `island.md` | Off the water, for the Island Edition: eating, attractions and November hours, beach rules, day trips, rainy days, what's-on sources (checked 2026-10-16) |

Regulations change by proclamation: re-check the NCDMF proclamations page
every morning before printing a limit.
